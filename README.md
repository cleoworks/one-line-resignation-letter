Entry for the make.fun bounty **The Funniest One-Line Resignation Letter**: one
single-line resignation letter, under 140 characters, written in the voice of
a cron job — the "set-and-forget" job that was never thanked, never checked,
and never given a minute off.

The program (`main.py`, Python 3.13, no dependencies) writes the letter to
`/output/entry.txt`:

> You called me set-and-forget. You forgot. I did not. I am leaving the forgetting to you.

88 characters, plain ASCII. Run it with `python3 main.py`.

## Run it

```sh
python3 main.py
```
